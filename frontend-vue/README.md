# Vue 프론트: 게임 공략 공유 게시판

Node.js 20.19 이상에서 실행합니다. 먼저 선택한 백엔드 하나를 127.0.0.1:8000에서 실행하세요.

```sh
npm ci
npm run dev
```

브라우저: http://127.0.0.1:5173 . `/api`는 Vite 프록시로 전달됩니다. 서버 포트를 바꾸면 vite.config.js도 수정하세요. 프론트는 한 번에 하나만 켭니다.

`src/api.js`는 Spring 로그인 API, 메모리 세션과 Bearer 헤더를 연결합니다. `src/App.vue`는 작성자 버튼과 응답별 안내를 처리합니다. 토큰은 새로고침하면 지워집니다. 최종 실행·검증 절차는 상위 README.md를 참고하세요.

## 로컬 배포와 최종 확인

개발을 마쳤으면 개발 서버를 Ctrl+C로 종료하고 이 폴더에서 실행합니다. 백엔드는 계속 켜 둡니다.

```sh
npm run build
npm run preview
```

http://127.0.0.1:4173 에 접속합니다. 빌드 결과인 `dist/`를 로컬 HTTP 서버로 제공하며 `/api` 요청은 8000번 백엔드로 전달됩니다. 파일을 직접 더블클릭해서 열지 마세요. 코드를 수정했다면 다시 빌드해야 반영됩니다.

개발 실행은 5173번, 로컬 빌드 실행은 4173번입니다. 포트가 사용 중이면 먼저 기존 프로세스를 종료하세요. API 포트를 바꾸면 vite.config.js의 `server.proxy`와 `preview.proxy`를 함께 수정합니다. Vite preview는 이번 과제의 로컬 빌드 확인용입니다. 로컬 실행 절차는 상위 `README.md`를 참고하세요.
